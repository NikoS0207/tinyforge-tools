# QuickForge Digital — Freelancer.com launch pack

## Recommended headline
Spreadsheet Dashboards | Web Calculators | Presentation & Thumbnail Design

## Profile summary
I build focused digital deliverables for small projects: Excel/Google Sheets dashboards and formulas, responsive HTML/JavaScript calculators, presentation redesigns, and YouTube thumbnails.

My approach is simple: clear scope, practical files, and fast delivery. I do not promise business outcomes I cannot control. I focus on producing the actual asset you asked for and keeping it editable whenever the format allows.

Useful project types:
- Excel / Google Sheets formulas, trackers, KPI dashboards and charts
- Existing spreadsheet cleanup and automation
- HTML/CSS/JavaScript calculators and mini-tools
- PowerPoint slide redesign and visual cleanup
- YouTube thumbnail design from supplied content and references

I can work from an existing file, rough notes, a formula, a screenshot, or a written brief.

## Skills to add
Microsoft Excel; Google Sheets; Excel Formula; Data Visualization; Dashboard; JavaScript; HTML; CSS; Web Development; PowerPoint; Presentation Design; Graphic Design; YouTube; Data Entry

## Proposal template — spreadsheet
Hi — I can handle this as a focused spreadsheet job. I can clean the structure, build/fix the formulas, and make the result reusable instead of hard-coding the output. If you send the current file plus the exact result/KPIs you need, I can start from that and keep the workbook editable.

## Proposal template — web calculator
Hi — I can turn this into a responsive HTML/CSS/JavaScript calculator and include the source files. If you already have the formula or spreadsheet logic, send it over; otherwise I can translate the written calculation rules into the tool. I’ll keep the interface simple and test the edge cases before delivery.

## Proposal template — presentation
Hi — I can redesign the existing deck without changing the meaning of your content. I’ll focus on spacing, hierarchy, typography, consistency and cleaner visuals, then return an editable presentation. Send the current deck and any style/brand reference you want followed.

## Proposal template — thumbnail
Hi — I can design this as a clean 1280×720 YouTube thumbnail around the specific video idea and your channel style. Send the title/topic, any text that must appear, assets you want included, and 1–3 references you like. I don’t promise view/CTR outcomes; I’ll focus on a clear, professional thumbnail.

## Bid rule
Never mass-send the exact same proposal. Rewrite the first 2–3 sentences around the client's actual brief, mention one concrete deliverable, and only bid on work that can genuinely be completed.
