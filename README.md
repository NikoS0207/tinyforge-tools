# TinyForge Tools

Focused offline utilities for indie game developers.

## Live products
- GrindScope — XP & Progression Visualizer: https://nikos0207.itch.io/grindscope-xp-progression-visualizer
- EconScope — Game Economy Stress Tester: https://nikos0207.itch.io/econscope-game-economy-stress-tester
- LootSim — Loot Table & Dry-Streak Simulator: https://nikos0207.itch.io/lootsim-loot-table-dry-streak-simulator

No subscriptions. No telemetry. Tools run locally in a modern browser after download.
