# TinyForge Game Tools

Free browser calculators and focused offline utilities for indie game developers working on **RNG, pity systems, XP progression and game economies**.

**Live site:** https://nikos0207.github.io/tinyforge-tools/

## Free browser tools

- [DropChance](https://nikos0207.github.io/tinyforge-tools/dropchance/) — repeated-attempt drop probability and confidence thresholds.
- [Hard Pity Calculator](https://nikos0207.github.io/tinyforge-tools/pity-calculator/) — compare base RNG with a guaranteed hard-pity pull.
- [XP & Leveling Time Calculator](https://nikos0207.github.io/tinyforge-tools/xp-calculator/) — turn an XP curve into total XP, hours and sessions.
- [Game Economy Faucet & Sink Calculator](https://nikos0207.github.io/tinyforge-tools/economy-calculator/) — estimate currency flow and first-pass inflation pressure.
